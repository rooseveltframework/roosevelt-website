This project's versioning tracks Roosevelt's versioning. When some version numbers are skipped, it's because the website was not updated for that version of Roosevelt.

- Added a test suite, run by `npm test` alongside the linters and by CI on every push. It does a production build and then checks what the build produced: that every page has a title, that no page links to something that was not built, and that the search index is consistent with the pages on disk.
- Fixed various bugs.
